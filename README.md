# Unterricht

NEXORA GAMING
=============

1. Den Ordner NEXORA_GAMING erstellen.
2. Die Homepage als index.html speichern.
3. Einen Unterordner namens spiele erstellen.
4. Den Spiele-Code darin als index.html speichern.
5. Die Hauptdatei index.html im Browser öffnen.

Enthaltene Spiele:
- Space Shooter
- Neon Snake
- Neon Racing
- Block World
- Zombie Survival
- Jump & Run
- Tower Defense
- Duo Arena

Hinweis:
Duo Arena ist ein lokaler Zwei-Spieler-Modus
an einer Tastatur, kein Online-Multiplayer.

Die Spiele laufen direkt im Browser.
